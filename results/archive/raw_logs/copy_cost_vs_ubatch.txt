# NOTE (added after the run): interpretation caution
#
# The numbers above are NOT clean per-ubatch times for the earlier cells.
#
# llama-bench runs the graph more than once per test (graph capture/warmup, then
# the measured run), and both runs print through the same per-ubatch timer. So:
#   - the FIRST printed ubatch row of a test includes the capture/warmup pass
#   - the per-ubatch counter is only reset when a NEW graph is built, so a reused
#     graph accumulates and prints 94 instead of 48
#
# For p == ub == 1024 with -p 1024 this means the printed "4x" is really 2 test
# passes x 1 ubatch each, i.e. 2 runs of a single ubatch, not 4.
# For -p 2048 with -ub 1024 there are 2 ubatches per pass, so the printed 4 rows
# are the 2 ubatches of the capture pass and the 2 ubatches of the measured pass.
# The absolute per-ubatch times are still valid; the count of rows is not a count
# of real passes.
#
# Separate clean single-ubatch data is in ub512_single.txt.
